How to read inventory status

Ready: available items exceed the warning threshold. Low: 1–threshold items available. Consumed: every listed item is explicitly consumed. Unknown: no reliable stock count, no items, or items awaiting approval. Freshness is independent of stock status. A snapshot older than 24 hours is labelled stale; this is a dashboard rule, not a workflow scheduling rule. Refresh reads stored D1 data. Run the collector to update it.
